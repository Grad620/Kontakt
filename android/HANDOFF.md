## Ключевые решения (не пересматривать без причины)
- Только официальные интерфейсы VK (VK ID SDK, api.vk.ru/method). Капчу и лимиты не обходим. Токен хранится в Android Keystore (AES-GCM).
- minSdk 34 (Android 14) по ТЗ, compileSdk/targetSdk 35.
- Тема VK Classic **отложена** по разделу 25 ТЗ (создавать только по просьбе пользователя); архитектура тем должна допускать добавление стиля.
- Размытие под панелью не реализовано (только полупрозрачность). Не называть это «blur». «Облегчённый» режим эффектов: непрозрачная панель без тени, без анимаций переходов.
- Музыка VK недоступна через разрешённые интерфейсы (audio.* закрыт) — экран «Музыка» честно объясняет это.
- Права `messages`, `wall`, `friends` VK выдаёт только по запросу в поддержку — без них чаты и лента показывают «Нет доступа».
- Рекомендации — собственные, только на устройстве; сигналы: время просмотра, пропуск, «Интересно», «Не интересно».

## Что реально проверено
- Окружение: облачный контейнер без доступа к Gradle/Maven/Google/VK-репозиториям; Android SDK нет. **APK здесь собрать нельзя. Ни одна сборка не выполнялась.**
- Компилятор Kotlin 2.0.21 из Gradle (`/opt/gradle-8.14.3/lib`) компилирует и тестирует «чистый» Kotlin: `bash tools/verify-core.sh` → **OK, 65 тестов** (фильтр рекламы и мусора с защитой сборов на помощь, Recommender, FeedMapping, ForYouRepository с поддельным загрузчиком, NavConfig, DiagnosticsLog, ColorMath/AccentPalette с проверкой контраста 8 акцентов × 2 темы).
- Статически (грубым скриптом) проверено, что все внутренние импорты `app.kontakt.client.*` указывают на существующие объявления. Типы и сигнатуры Compose/Android так не проверить.
