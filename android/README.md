# Kontakt — неофициальный клиент ВКонтакте для Android

Версия **0.2.0 — каркас с лентой рекомендаций и настройками**. Это не готовая замена приложению VK. Ниже честно: что написано, что реально проверено и что VK не разрешает.

Требуется Android 14 и новее (minSdk 34). Целевое устройство для проверки: iQOO Neo 10.

## Что есть сейчас

«Проверено компиляцией и тестами» значит: код этого раздела скомпилирован настоящим компилятором Kotlin и прогнан через юнит-тесты (65 штук, `tools/verify-core.sh`). «Написано, не компилировалось» значит: код написан и просмотрен глазами, но Android-часть (Compose, OkHttp, DataStore, VK ID) в среде разработки собрать нельзя. Первая настоящая сборка будет в GitHub Actions.

## Главное ограничение VK

Для пользовательского токена права `messages` (чаты), `wall` и `friends` (лента) VK выдаёт **только в исключительных случаях по запросу в поддержку** (`devsupport@corp.vk.com`). Без них «Чаты» и режим «Подписки» покажут «Нет доступа к данным», а не пустые или выдуманные данные. Режим «Для вас» дополнительно использует `newsfeed.search` и `wall.get` сообществ: **будут ли они работать с базовым токеном, не проверено**. Если VK откажет, экран честно покажет, какие источники недоступны. Kontakt эти ограничения не обходит: ни чужих токенов, ни неофициальных приложений, ни капчи.

## Рекомендации и фильтр

Подробно: `docs/RECOMMENDER.md`. Коротко: всё работает на телефоне, ничего никуда не отправляется. ## Как получить APK со смартфона (без компьютера)

Нужен бесплатный аккаунт GitHub.

1. Создайте репозиторий (кнопка «+» → New repository). **Выберите Private**: в APK попадает идентификатор приложения VK (и секрет из настроек SDK), а артефакты сборок публичных репозиториев может скачать любой.
2. В репозитории: **Add file → Upload files** → выберите файл `kontakt-project.zip` (он выдан в чате) → Commit. Если телефон поменял имя, переименуйте файл **строго в `kontakt-project.zip`** (старое имя `vg-project.zip` тоже подходит).
3. **Add file → Create new file**, в поле имени введите `.github/workflows/build.yml`, вставьте содержимое файла `build.yml` из чата → Commit.
4. Вкладка **Actions** → «Build Kontakt APK» → **Run workflow**. Сборка идёт несколько минут (первая дольше).
5. Откройте завершённый запуск → внизу **Artifacts → Kontakt-debug-apk**. Скачается zip. Распакуйте его в «Файлах» и откройте `app-debug.apk`. Android попросит разрешить установку из этого источника.

Если сборка упала: откройте шаг с красным крестиком, скопируйте последние ~40 строк лога и отправьте Claude.

### Лимиты бесплатного GitHub

По данным, опубликованным в 2026 году: в приватных репозиториях на плане Free — 2000 минут Actions в месяц и 500 МБ хранилища артефактов; в публичных стандартные раннеры бесплатны без лимита минут. Сборка Android обычно занимает несколько минут, workflow хранит APK 7 дней, чтобы не забивать квоту. Условия могут меняться: смотрите Settings → Billing у себя.

## Подключить VK ID (чтобы вход заработал)

Без этого приложение соберётся, но экран входа скажет «Нужна настройка».

1. Зарегистрируйте приложение в кабинете VK ID для разработчиков (найдите «VK ID регистрация приложения» в документации VK; названия пунктов меню у VK меняются). Платформа — Android.
2. Укажите там:
   - **Package name / application ID: `com.kontakt.app`**. Не указывайте `app.kontakt.client`: это Kotlin/Android `namespace`, а установленный APK имеет `applicationId = com.kontakt.app`.
   - SHA-1 отпечаток сертификата: `2D:8F:47:E1:62:7E:35:EC:2B:A6:51:B7:2D:4E:1B:48:75:3F:E3:53` (фиксированный debug-ключ проекта, `app/debug.keystore`)
3. По README VK ID SDK понадобятся: ID приложения, его секретное значение, redirect host `vk.ru` и scheme `vk<ID приложения>` (последние два уже подставляются автоматически).
4. В GitHub: Settings → Secrets and variables → Actions:
   - Secrets: `VK_CLIENT_ID`, `VK_CLIENT_SECRET`
   - `VK_SCOPES` пока оставьте пустым. Не вставляйте сюда старые разрешения API (`friends,wall,messages`) наугад: scopes VK ID и разрешения старого VK API — не одно и то же. Сначала проверяем базовый вход, затем отдельно подтверждаем доступность каждого метода API.
5. Запустите сборку заново (Actions → Run workflow).

### Что секрет, а что нет
- Не в репозитории: `VK_CLIENT_SECRET`, токены, пароли. Они передаются только через GitHub Secrets.
- Внимание: по README VK ID SDK значение `VKIDClientSecret` подставляется в манифест, то есть **попадает внутрь APK**. Поэтому APK нельзя раздавать другим людям, а репозиторий держите приватным. Подходит ли это для публичного распространения — нужно уточнить в документации VK ID. Пока считайте Kontakt личной сборкой.
- Не секрет: имя пакета, SHA-1 отпечаток, `VK_CLIENT_ID`, `app/debug.keystore` (стандартный debug-ключ с паролем `android`, подходит только для личной установки).

## Безопасность

- Токен хранится зашифрованным, в логи не пишется, передаётся в теле POST-запроса, не в адресе.
- Пароль VK вводится только на странице VK ID; формы пароля в Kontakt нет.
- При ответе VK с кодом 5 токен удаляется и показывается экран входа.
- Капча не обходится: показывается сообщение.
- Резервное копирование Android отключено (`allowBackup=false`).
- Из разрешений Android только `INTERNET` и `ACCESS_NETWORK_STATE` (узнать, есть ли сеть). Рекламы и аналитики нет.
- Выход удаляет токен, обучение ленты, счётчики, журнал и кеш картинок с устройства. Отзыв токена на стороне VK при выходе не реализован.
- Журнал сети хранится только в памяти и не содержит токенов, сообщений и содержимого ответов VK.

## Производительность (что заложено, не измерено)

- Списки на `LazyColumn` с ключами элементов, постраничная загрузка (чаты 30, лента 20), подгрузка за 4 элемента до конца.
- Один активный запрос на список, обновление отменяет подгрузку, дубли элементов отбрасываются.
- Запрос отменяется вместе со ViewModel (экран закрыт — сетевой вызов отменён).
- Картинки: Coil, кеш 20% памяти приложения и 64 МБ на диске, аватары декодируются сразу нужного размера, фото в ленте берутся ≤ 800 px.
- Вкладки не перезагружаются: ViewModel и позиция прокрутки сохраняются при переключении.
- Реальные замеры холодного старта и плавности **не проводились**. Сравнений с Telegram нет и обещаний тоже.

## Структура

```
app/src/main/kotlin/app/kontakt/client/
  auth/   вход через VK ID, зашифрованное хранилище токена
  net/    клиент VK API (троттлинг, ограниченные повторы), разбор ответов и ошибок, модели
  data/   репозитории (профиль, чаты, лента «Подписки», лента «Для вас»), разбор постов
  rec/    фильтр рекламы и мусора, рекомендатель, профиль интересов, сигналы просмотра
  core/   постраничная загрузка, список вкладок, журнал, мониторинг сети, настройки (DataStore)
  ui/     тема и палитры, компоненты, нижняя панель, навигация, экраны
app/src/test/   юнит-тесты (ядро проверяется скриптом tools/verify-core.sh)
docs/           возможности VK API, рекомендатель, заметки по Telegram
tools/          проверка «чистого» ядра настоящим компилятором Kotlin
.github/workflows/build.yml   облачная сборка APK
```

Имя пакета остаётся `app.kontakt.client` (прежнее название проекта: VG): менять его незачем, пользователю оно не видно.

Стек: Kotlin 2.1.21, Jetpack Compose (BOM 2025.06.01), Material 3, Coroutines/Flow, OkHttp, kotlinx.serialization, Coil 2.7, DataStore, VK ID SDK 2.0.0, AGP 8.11.1, Gradle 8.14.3, JDK 17. Версии подобраны по совместимости, но **не проверялись сборкой**; версия VK ID SDK взята из его README и не подтверждена как последняя.
