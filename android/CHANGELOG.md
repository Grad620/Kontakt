# CHANGELOG — Kontakt

## Дизайн-ветка (не собиралась, ядро цветов проверено 77 тестами)
- Два полноценных стиля: Kontakt (в духе Telegram) и VK Classic (цветная шапка, боковое меню, плоские блоки); выбор с миниатюрами в настройках.
- Палитры на стиль и тему (`NeutralSet`), акцентный цвет читается на фоне и карточках во всех сочетаниях; шапка VK Classic по контрасту.
- Состояния: скелетоны загрузки, пустые и ошибочные состояния с иконкой, баннер недоступных источников.
- Чаты: поле поиска-капсула, счётчик непрочитанного, подсветка непрочитанных в VK Classic. Лента: вкладки «Для вас / Подписки», счётчики лайков и комментариев, плавное удаление карточек. Профиль и музыка: центрированный профиль, честный экран музыки.
- Анимации (пружинка вкладки, подчёркивание, переходы) отключаются режимом «Облегчённые» эффекты; вход прокручивается на маленьких экранах.

## 0.2.0 (сессия 3; не собиралась, ядро проверено тестами)
- Проект получил название Kontakt (пакет прежний). Требуется Android 14+ (minSdk 34).
- Ядро рекомендаций (`rec/`, `data/`): токенайзер, профиль интересов, ранжирование с разнообразием, сигналы просмотра, фильтр рекламы / мошенничества / нежелательных товаров с защитой обычных сборов на помощь, рекомендатель с «Почему я это вижу?», скрытие источников, локальное хранилище. 65 юнит-тестов проходят (`tools/verify-core.sh`).
- Лента: режимы «Для вас» (подписки + поиск + стены любимых сообществ) и «Подписки»; «Интересно», «Не интересно», «Не показывать источник».
- Сеть: троттлинг запросов, ограниченные повторы, мониторинг сети, журнал диагностики без токенов.
- Дизайн: 8 акцентов (контраст проверен тестами), светлая/тёмная тема, режим эффектов, токены стиля (задел под VK Classic).
- Навигация: плавающая полупрозрачная нижняя панель, настраиваемые вкладки.
- Экран настроек (внешний вид, вкладки, фильтры, рекомендации, аккаунт, сеть и диагностика). Из профиля убраны тема и выход.
- Сборка: CI сначала собирает APK и загружает артефакт `Kontakt-debug-apk`, затем запускает тесты; принимает `kontakt-project.zip`.
- Документы: `PROJECT_SPEC.md`, `HANDOFF.md`, `NEXT_STEPS.md`, `BUILD_NOTES.md`, `docs/RECOMMENDER.md`.
