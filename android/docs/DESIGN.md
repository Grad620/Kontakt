# DESIGN — дизайн-система Kontakt

Ответственность: дизайн, UI/UX, визуальная целостность. Техническая часть VK API, авторизация и сборка — у других участников работы (см. `HANDOFF.md`).

## Два стиля интерфейса
Выбор — Настройки → Внешний вид → «Стиль интерфейса» (миниатюры показывают устройство каждого стиля). Значение хранится в DataStore (`interface_style`), неизвестное значение превращается в Kontakt (`KontaktStyleId.parse`).

| | Kontakt (в духе Telegram) | VK Classic |
|---|---|---|
| Навигация | нижняя панель вкладок, иконка слегка «пружинит» при выборе | **нет** нижней панели: цветная шапка с кнопкой меню и боковая шторка с теми же разделами и настройками |
| Шапка | прозрачная, заголовок слева, кнопка настроек | заливка акцента (светлая тема) или цвет карточки (тёмная), текст по контрасту |
| Блоки | мягкие карточки r=14 dp с отступом 12 dp | плоские блоки на всю ширину, зазор 8 dp, без скруглений |
| Чаты | аватар 52 dp, строка 76 dp, счётчик-круг | аватар 48 dp, строка 68 dp, непрочитанные подсвечены, счётчик-прямоугольник r=4 |
| Типографика | 16/22 для текста, подписи разделов моноширинные (отсылка к техничным экранам) | компактнее: 15/21, заголовки Medium |
| Фон | светлая `#F0F2F5`, тёмная `#0E1621`, карточки `#FFFFFF` / `#17212B` | светлая `#EDEEF0`, тёмная `#19191A`, карточки `#FFFFFF` / `#222223` |

«Синий» (голубой) акцент в VK Classic светлой темы — классический синий шапки VK `#4A76A8` (белый текст, контраст ≈ 4,7).
Определение VK Classic: оформление мобильного VK до обновления 28.08.2026 (шапка и меню вместо нижней панели), не старое приложение и не веб-обёртка.

## Где что лежит
- `ui/theme/ColorMath.kt` — чистая математика цвета, `Neutrals.of(style, dark)` (наборы `NeutralSet`), `AccentPalette.*(id, dark, style)`. Проверяется компилятором и тестами без Android.
- `ui/theme/Theme.kt` — `KontaktStyle` (токены: classic, форма, отступы, размеры чатов, подсветка непрочитанных), `KontaktColors` (акцентный текст, шапка VK Classic, мягкая подложка акцента), типографика и формы на стиль, цвета строки состояния.
- `ui/components/Components.kt` — шапки (`ScreenHeader`, `SubScreenHeader`, `ClassicBar`), `StatusBarBackdrop`, `SectionCard`, `SkeletonList`, `StateMessage`/`ErrorState` (с иконкой), `InfoBanner`, `LinkRow`, `SearchField`, `CountBadge`, `SegmentedTabs`.
- `ui/MainShell.kt` — оболочка: нижняя панель (Kontakt) или `ModalNavigationDrawer` (VK Classic).
- Экраны берут размеры и формы из `Kontakt.style`, цвета — из `MaterialTheme.colorScheme` и `Kontakt.colors`; жёстко заданных цветов нет (кроме палитры аватаров и логотипа входа).

## Правила
- Акцентный цвет как текст/значок на фоне — только `Kontakt.colors.accentText` (контраст ≥ 4,5 с фоном и карточкой во всех сочетаниях стиль × тема × акцент). Сырая заливка (`primary`) — только для кнопок и бейджей, где текст подбирается по контрасту.
- Режим «Облегчённые» эффекты отключает анимации: переходы, пружинки панели, подчёркивание вкладок, мерцание скелетонов, пульс логотипа, анимацию удаления карточек.
- Лайки и комментарии VK в ленте — только счётчики, не кнопки. Нет доступа к данным VK — экран говорит об этом, а не рисует пустую имитацию.
- Размытие под панелью не реализовано; «стекло» (`glass*`) в стиле Kontakt сейчас не используется, токены оставлены для режима «Полные эффекты».

## Что проверено, а что нет
- Проверено (`bash tools/verify-core.sh`, 77 тестов): читаемость основного/вторичного текста, различимость карточки и фона, обводки, акцентный текст и текст на заливке во всех 2 × 2 × N сочетаниях, шапка VK Classic, разбор значения стиля.
- Проверено грубо: синтаксис всех изменённых Compose-файлов (kotlinc без Android-зависимостей: ошибок разбора нет), импорты проектных символов.
- **Не проверено**: компиляция Compose-кода (нужна сборка в GitHub Actions) и внешний вид на телефоне. Положения, зависящие от устройства (строка состояния под цветной шапкой, жест шторки от края и системный «назад», вид на iQOO Neo 10), требуют проверки руками.
