# Заметки по Telegram для Android

Изучено честно и ограниченно: публичный README `github.com/DrKLO/Telegram` и первые ~100 тыс. символов файла `ImageLoader.java`. Остальной репозиторий не разбирался. Выводы ниже о других частях Telegram в этот список не входят.

## Лицензия

Репозиторий под GPL-2.0. README просит: свой `api_id`, не называть приложение «Telegram» и не использовать его логотип, публиковать свой код для соблюдения лицензий. **В VG код Telegram не копировался и не подключался**, VG использует собственную реализацию, поэтому условия GPL на него не распространяются. Если когда-нибудь понадобится взять оттуда код, лицензию нужно проверять заново.

## Что видно в ImageLoader и как это учтено в VG

| Приём в Telegram | Что сделано в VG |
|---|---|
| Несколько LRU-кешей в памяти, отдельный для маленьких картинок (до 80dp) | Кеш Coil: 20% памяти приложения |
| Кеш на диске, запись через временный файл с переименованием | Дисковый кеш Coil 64 МБ (Coil сам пишет безопасно) |
| Загрузка и декодирование в отдельных очередях, не на главном потоке | Корутины, сеть на потоках OkHttp, декодирование Coil вне UI-потока |
| Уменьшение через `inSampleSize` под нужный размер | Аватары запрашиваются сразу нужного размера, фото ≤ 800 px |
| Один запрос на одну картинку, несколько получателей | Coil объединяет одинаковые запросы; в списках один активный запрос на экран |

Это сопоставление идей, а не заимствование реализации. Плавность прокрутки и скорость запуска VG пока **не измерялись**.
