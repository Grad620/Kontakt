# Возможности VK API для Kontakt

Составлено 20.10.2026 по официальным страницам dev.vk.ru, которые удалось открыть. Часть страниц документации показывала «технические работы» или не открылась, это отмечено. Статусы «реализовано» значат, что код написан, но **на реальном аккаунте не проверялся**.

| Функция | Метод / механизм | Права | Доступность для стороннего клиента | Ограничения | Статус в Kontakt 0.2 |
|---|---|---|---|---|---|
| Авторизация | VK ID SDK для Android (`com.vk.id:vkid`), OAuth | базовый доступ | Доступна. Базовый доступ (имя, фото, пол, дата рождения) выдаётся сразу после создания приложения | Нужны ID приложения, SHA-1 отпечаток, redirect `vk<ID>://vk.ru`. SDK по README требует секрет в манифесте | Реализовано, не проверено |
| Профиль | `users.get` | базовый | Ожидается доступной с базовым доступом. Страницу метода открыть не удалось | — | Реализовано, не проверено |
| Список диалогов | `messages.getConversations` | `messages` | Страницу метода открыть не удалось. Для `messages.send` документация говорит: право `messages` для пользовательского токена выдаётся в исключительных случаях по запросу в поддержку. Считаю, что то же верно для чтения | Без права придёт ошибка доступа | Код есть; без права покажет «Нет доступа» |
| История сообщений | `messages.getHistory` | `messages` | То же | — | Не реализовано |
| Отправка сообщений | `messages.send` | `messages` | Только по запросу в поддержку VK (из документации метода) | Токен из standalone-приложения (Implicit Flow). Для сообществ есть токен сообщества | Не реализовано |
| Получение обновлений | Long Poll пользователя / Callback API сообществ | `messages` | Не проверено | Callback API работает для сообществ, не для личных сообщений | Не реализовано |
| Лента | `newsfeed.get` | `wall` + `friends` | Документация метода: эти права выдаются только в исключительных случаях по запросу в поддержку. При проверке на странице висело уведомление о техработах | Пагинация через `start_from`/`next_from` | Код есть; без права покажет «Нет доступа» |
| Поиск публикаций (режим «Для вас») | `newsfeed.search` | не проверено | **Не проверено**, достаточно ли базового токена. Документацию метода открыть не удалось | Если VK откажет, источник отключается на 10 минут, экран сообщает об этом | Код есть, не проверено |
| Стена сообщества (режим «Для вас») | `wall.get` с `owner_id=-<id>` | не проверено | **Не проверено**: для чужих стен права `wall` могут требоваться | То же | Код есть, не проверено |
| Фотографии | вложения постов (`attachments[].photo.sizes`), `photos.*` | `photos` | Права `photos` нет в явном списке «исключительных»; нужны ли дополнительные условия — не проверено | Берутся превью до 800 px | Отображение фото в ленте реализовано |
| Друзья | `friends.get` | `friends` | По документации `newsfeed.get`, право `friends` выдаётся по запросу | — | Не реализовано |
| Лайки и комментарии | `likes.add`, `wall.createComment` | `wall` | Требует `wall` (по запросу) | — | Счётчики показываются, действия не реализованы |
| Стена пользователя | `wall.get` | `wall` | Требует `wall` (по запросу) | — | Не реализовано |
| Аудиозаписи, поиск, воспроизведение | `audio.*` | — | Закрыто для сторонних приложений: в декабре 2016 VK объявил об отключении публичного API аудио. Актуальную официальную страницу `audio.get` открыть не удалось | Неофициальные токены/API использовать нельзя | Не реализовано, это решение, а не пропуск |

## Что можно сделать с музыкой законно

Плеер для аудиофайлов на самом телефоне: Media3, очередь, мини-плеер, уведомление с управлением, аудиофокус. Для него нужно разрешение на чтение аудио, VK не участвует. Не реализовано в 0.2.

## Что делать с правами messages / wall / friends

Написать в поддержку VK (`devsupport@corp.vk.com`) от имени своего приложения, описать, что это личный клиент и зачем нужны права. Решение за VK. После одобрения добавьте права в переменную `VK_SCOPES` и пересоберите.
