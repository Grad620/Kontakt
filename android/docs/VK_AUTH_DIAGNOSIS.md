# Вход через VK: ошибка `invalid_request` / `Security Error`

Дата разбора: 24–25 октября 2026. Здесь отдельно записано, что **доказано** исходниками и документацией, а что остаётся **предположением**.

## Что доказано

1. **Текст ошибки приходит с сервера VK, а не из Kontakt и не из SDK.** Строки `Security Error` нет ни в нашем коде, ни в исходниках `com.vk:android-sdk-core:4.1.0` (проверено поиском по обоим деревьям). Так что ошибка не из инициализации SDK и не из возврата результата в приложение, а из ответа VK на запрос авторизации.
2. **Что именно отправлял прежний вход.** `VK.login()` из SDK 4.1.0 открывает приложение VK (если оно установлено) или `VKWebViewAuthActivity`, которая грузит `https://api.vk.com/oauth/authorize?client_id=…&response_type=token&redirect_uri=https://oauth.vk.com/blank.html&display=mobile&revoke=1` — старый «неявный» OAuth-поток, домен `vk.com`. Код: `VKAuthParams`, `VKWebViewAuthActivity.getUrlParams`.
3. **Результат окна терялся.** Любой неуспешный результат (кнопка «Назад», ошибка загрузки, `error`/`cancel` в ответе) SDK 4.1.0 превращает в `VKAuthException(authError = "Authentication cancelled with activity code = N")`, а текст исключения всегда «Auth canceled». По этим данным нельзя отличить закрытие окна от ошибки VK (`VKAuthResultContract.parseResult`).
4. **Официальный современный способ — VK ID SDK.** Его v2.7.3 (сентябрь 2026) открывает `https://id.vk.ru/authorize` с `response_type=code` и PKCE, возвращается по `vk{ID}://vk.ru/blank.html`. В его CHANGELOG (2.5.1): «ВКонтакте переходит на домен vk.ru — теперь все API-интеграции и авторизации будут доступны только через него». В документации VK ID сказано, что Standalone-приложения из dev.vk.com перенесены в сервис VK ID.
5. **Ключ в APK для входа не нужен.** В исходниках VK ID SDK 2.7.3 обмен кода на токен, обновление и выход не используют `client_secret`; он нужен только для статистики и необязательного списка провайдеров тихого входа, при отказе сервера SDK берёт встроенный список (`TrustedProvidersCache`).

## Что остаётся предположением

- **Прямого описания ошибки `Security Error` в документации VK нет.** Вывод «старый запрос не подходит ID приложения из VK ID» складывается из пунктов 2 и 4 и из того, что приложение регистрировалось в кабинете VK ID. Это наиболее вероятная причина, но не доказанная.
- Сторонние обсуждения (не официальные, не проверены) пишут, что неявный поток и OAuth 2.0 VK ограничивает, а обычное создание приложений в 2026 году недоступно. Старые заметки про «Security Error» связывают его с устаревшей сессией VK в веб-входе; для Android это не подтверждено.

Подтвердить причину окончательно можно только запуском на устройстве.

## Что изменено в Kontakt

- Вход переведён на VK ID SDK целиком; классический SDK, его хранилище и `VK.login()` удалены. Оба механизма одновременно не используются.
- Вход запускается от области процесса, а не от Activity: поворот экрана, пока открыто окно VK, не теряет результат.
- `AuthFlow` (чистая логика, покрыта тестами): одна попытка за раз; любой исход снимает загрузку; сохранение токена проверяется; через 5 минут без ответа загрузка снимается; токен не попадает в состояние и сообщения.
- Ошибки VK ID SDK разбираются по типам (`Canceled`, `FailedApiCall`, `FailedOAuth`, `FailedOAuthState`, `FailedRedirectActivity`, `NoBrowserAvailable`) и показываются с очищенным описанием: значения `code`, `state`, `device_id`, токены и длинные токеноподобные строки скрываются.
- `client_secret` в APK не кладётся.
- По умолчанию запрашивается только базовое право: права вне списка, включённого в кабинете VK ID, делают запрос недействительным.

## Проверка на устройстве

1. Скачай APK из последнего успешного запуска Kontakt Android CI и установи его поверх старого (подпись та же).
2. Открой Настройки → «О приложении» и сверь строку «сборка …» с началом хэша последнего коммита ветки.
3. На экране входа нажми «Войти через VK». Ожидаемо: откроется приложение VK («Продолжить как …») или страница `id.vk.ru` в браузере.
4. Подтверди вход. Ожидаемо: открывается основной интерфейс Kontakt.
5. Если на странице VK ошибка, пришли её скриншот целиком. Если Kontakt показал красное сообщение, пришли скриншот сообщения. Тексты уже очищены от токенов и кодов.
6. После входа открой Настройки → «Сеть и диагностика» → «Проверить доступ к VK API» и пришли, какие методы доступны.

## Данные из кабинета VK, которые могут понадобиться

Нужны, только если вход всё равно завершится ошибкой, и каждое — по конкретной причине:

- В каком кабинете создано приложение с ID из `VK_STANDALONE_APP_ID` (VK ID, id.vk.com → «Бизнес», или старый раздел для разработчиков): VK ID SDK работает только с приложениями VK ID.
- Статус приложения и перечень включённых прав: запрос прав вне списка отклоняется.
