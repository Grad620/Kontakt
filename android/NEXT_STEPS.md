## Что делать после первой сборки в GitHub Actions (главный следующий шаг)
- Пользователь присылает конец лога (или пишет, что всё собралось и APK установился).
- Исправлять ошибки компиляции по логу, сохраняя рабочее ядро (после каждой правки `bash tools/verify-core.sh`).
- Если APK установился: проверить на iQOO Neo 10 вход через VK ID (нужен ID приложения и SHA-1 из README), затем ленту, затем настройки; записывать, что реально работает.

## Задачи, которые можно делать без сборки
- Тесты для `Paginator` и `VkResponseParser` в окружении Gradle (CI).
- Реальное размытие под панелью (GraphicsLayer + RenderEffect, Android 12+) — только как отдельный выбор «Полные эффекты»; не называть blur, пока нет.
- Локальный музыкальный плеер (Media3) для файлов на телефоне.
- Проверить документацию VK по `video.*` и `newsfeed.search` (когда откроется) и обновить `docs/VK_API_MATRIX.md`.

## Отложено / не реализовано (честно)
- Экран переписки и отправка сообщений (нужно право messages).
- Друзья, лайки/комментарии в VK (нужны права VK).
- Видео и Клипы; несколько аккаунтов; подарки VK; тема VK Classic (только по просьбе пользователя).

## Известные проблемы и риски
- Ни разу не выполнялась реальная сборка: первый запуск CI покажет ошибки компиляции.
- Версия `com.vk.id:vkid:2.0.0` и имена классов SDK не проверены.
- Неизвестно, работают ли `wall.get` / `newsfeed.search` с токеном без расширенных прав.
- Нет доступа к GitHub из контейнера: пользователь загружает архив в приватный репозиторий сам.
- В `RecommenderStore.kt` есть неиспользуемый импорт `kotlinx.serialization.Serializable` (только предупреждение).
